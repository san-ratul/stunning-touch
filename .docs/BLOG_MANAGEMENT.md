# Blog Management

## Content workflow
Draft → (review) → Publish, with optional scheduling and archiving.

1. **Create**: Admin → Blog Posts → “+ New Post”.
2. Fill title/slug (unique, kebab-case), excerpt, HTML content, category, tags, author.
3. Add **featured image** by path/URL or pick from the Media Library (with alt text — required for accessibility & SEO).
4. Complete the SEO block (SEO title with counter, meta description with counter, focus/secondary keywords, canonical, robots flags).
5. Save as **Draft** — drafts are never public.
6. **Publish** (sets published_at) or **Schedule** (future `scheduled_at`; goes live automatically once due — public queries require `status=published AND published_at <= now()`).
7. **Unpublish/Archive** any time. Deleting is permanent.

## Frontend rendering
- `/blog` — featured hero post + paginated grid (9/page) + category sidebar.
- `/blog/{slug}` — article page: category badge, author, date, reading time, featured image, share buttons (Twitter/Facebook/LinkedIn/Email), HTML content, tags, related tools (matched from focus/secondary keywords), related posts, JSON-LD `Article`, breadcrumbs.
- `/blog/category/{slug}` — per-category listing.
- Reading time is computed automatically (~200 wpm). View counts increment on each public view.

## Media Library (Admin → Media)
- Upload JPG/PNG/WebP/GIF/SVG/PDF/TXT/CSV ≤ 4 MB (MIME + extension validated).
- Copy URL button for use in posts; delete removes file + row.
- The post editor embeds an image picker from the media library.

## Blog Categories & Tags
- Categories: name/slug/description/active — appear in sidebar, filters, sitemap.
- Tags: created standalone or via AI output; inline rename; many-to-many with posts.

## Contact messages
Public contact form submissions (rate-limited 5/min, honeypot anti-spam) land in Admin → Messages: read/unread toggle, delete.

## AI-assisted posts
Posts generated by AI arrive as **drafts** marked `source=AI` (badge in the admin list). Review content, add a featured image + alt text, verify links, then publish. See AI_CONFIGURATION.md.
